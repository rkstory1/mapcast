# Script: The Pomodoro Technique (mapcast demo)

Status: demo. Replace this file for every video. Facts to check before using it for real: brief.md.
Format: one `### NN Title` heading and one fenced block per part. The block starts with a direction tag for the voice
([curious], [warm], [calm], [serious], [excited]). Write numbers the way they are said ("twenty five", "nineteen eighty
seven"); captions turn them back into digits. 10 to 30 seconds per part.

### 01 The student
```
[curious] In the late nineteen eighties, a university student in Rome could not finish a single chapter without drifting off. So he grabbed a kitchen timer shaped like a tomato, and made himself a deal.
```

### 02 The deal
```
[warm] Work for just a few minutes. Nothing else. Today, his trick is one of the most famous focus methods in the world. It is called the Pomodoro Technique.
```

### 03 The map
```
[calm] Here is the whole method in three steps. Focus, take a short break, and repeat.
```

### 04 Focus
```
[curious] Step one. Pick one task and set a timer for twenty five minutes. No email, no phone, no second task. Just one thing until the timer rings.
```

### 05 Break
```
[warm] Step two. When it rings, stop and take a five minute break. Stand up, get some water, look out the window.
```

### 06 Repeat
```
[warm] Step three. Repeat. After four rounds, take a longer break of fifteen to thirty minutes.
```

### 07 Why it works
```
[serious] It works because a timer you can see turns a huge job into one small round. And a break you know is coming makes the round easy to start.
```

### 08 Tonight
```
[warm] So pick one task tonight, set twenty five minutes, and start. Tell us in the comments which task you will try it on. And subscribe for more videos like this.
```
