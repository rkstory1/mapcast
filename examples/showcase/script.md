# Script: Parkinson's Law (mapcast demo, 30 s)

Status: the showcase example. Facts checked in brief.md.

### 01 The hook
```
[curious] A ten minute task can swallow your whole afternoon. In nineteen fifty five, a British historian put the reason into one line, in a half joking essay for The Economist.
```

### 02 The law
```
[serious] Work expands so as to fill the time available for its completion. Today we call it Parkinson's Law.
```

### 03 The flip
```
[warm] So flip it. Give the task less time. Set a deadline that feels a little too short, and the work shrinks to fit.
```
